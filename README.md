# KiraOS
A simple personal OS that can be run in the web!

<img width="1390" height="960" alt="image" src="https://github.com/user-attachments/assets/1a9b0443-efc9-4d86-be55-3f43e385a7c6" />

## Features
- Desktop-style interface
- Draggable application windows
- Image viewer
- Notes app
- Pixel editor
