# KiraOS
A simple personal OS that can be run in the web!

## Features
- Desktop-style interface
- Draggable application windows
- Image viewer
- Notes app
- Pixel editor

## Live demo
https://kira-iovenko.github.io/kiraOS/

## Build With
- HTML
- CSS
- JavaScript

## Project status
This project is still being developed. More apps and features will be added to KiraOS over time.
